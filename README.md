# Sistema de Ouvidoria

Plataforma web de ouvidoria com registro de manifestações, geração de protocolos, acompanhamento e painel administrativo.

## Objetivos

- Portal público com reclamações, denúncias, sugestões, elogios e solicitações.
- Protocolos para acompanhamento de manifestações.
- Fluxo de triagem, distribuição, tratamento e resposta.
- Painel administrativo com permissões e histórico de atividades.
- Relatórios e indicadores de atendimento.

## Stack planejada

- Next.js (TypeScript) para frontend e backend.
- PostgreSQL gerenciado para persistência de dados.
- Deploy de pré-visualização na Vercel.

## Segurança e privacidade

O repositório é público. Nunca inclua senhas, tokens, arquivos `.env`, dados pessoais reais ou anexos de cidadãos em commits. Manifestações, sobretudo informações de saúde, exigem autorização adequada, controle de acesso, armazenamento privado, trilhas de auditoria e práticas alinhadas à LGPD antes de uso real.
